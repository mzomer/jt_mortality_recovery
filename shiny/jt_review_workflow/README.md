# Joshua tree review workflow — v30

Immediate visual feedback is now consistent across all plot workflow buttons:

- Flag team review -> dark red immediately
- Resolved -> dark green immediately
- Accept -> dark green immediately and temporarily reads `Accepted`
- Correction needed -> dark orange immediately

Each button is briefly disabled after clicking to prevent accidental
double-clicks, while keeping the selected colour fully visible.

The shared Google Sheet workflow and all status logic are unchanged.
